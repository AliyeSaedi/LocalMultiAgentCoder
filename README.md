# LocalMultiAgentCoder
مجموعه ابزاری پیشرفته و سبک برای برنامه‌نویسی آفلاین با هوش مصنوعی که امکان اجرای مدل‌های زبانی بزرگ را به صورت کاملاً محلی و از طریق موتور اولاما فراهم می‌کند. این نرم‌افزار با بهره‌گیری از یک معماری چندعاملی و پشتیبانی کامل از زبان فارسی، فرآیند توسعه نرم‌افزار را تسهیل کرده و شامل قابلیت‌هایی نظیر ترجمه دوطرفه، مدیریت هوشمند تاریخچه گفتگوها، حالت‌های اجرای تکی و زنجیره‌ای، و رابط کاربری مدرن تیره است که به طور ویژه برای سیستم‌های دارای سخت‌افزار معمولی و بدون کارت گرافیک اختصاصی بهینه‌سازی شده است.

## 🇮🇷 نسخه فارسی

یک نرم‌افزار دسکتاپ مدرن و مینیمال برای اجرای مدل‌های زبانی بزرگ (LLM) به صورت **کاملاً آفلاین** و با استفاده از موتور **Ollama**[cite: 3]. این ابزار مجهز به معماری چندعاملی (Multi-Agent) است و به طور ویژه برای توسعه‌دهندگان فارسی‌زبان بهینه‌سازی شده است[cite: 3].

### ✨ ویژگی‌های کلیدی
* **معماری زنجیره‌ای:** ترکیب همزمان چند مدل (مترجم فارسی ➔ تحلیل‌گر منطق ➔ کدزن ➔ مترجم معکوس)[cite: 3].
* **مترجم دوطرفه هوشمند:** تبدیل پرامپت فارسی به انگلیسی فنی و ترجمه خروجی کدها به فارسی روان[cite: 3].
* **حالت اجرای دوگانه:** قابلیت سوییچ آسان بین حالت «تکی» و «چندتایی» (چندعاملی)[cite: 3].
* **رابط کاربری مدرن (RTL):** طراحی شده با تم تیره، راست‌چین و سازگار با استانداردهای برنامه‌نویسی[cite: 3].
* **مدیریت تاریخچه و امنیت داده‌ها:** ذخیره‌سازی محلی گفتگوها بدون اشغال حافظه رم (`ai_history.json`)[cite: 3].
* **ابزارهای پیشرفته:** تایمر زنده، لودر متحرک، دکمه توقف پردازش و کپی سریع خروجی[cite: 3].
* **سازگار با سیستم‌های ضعیف:** بهینه‌سازی‌شده برای اجرا روی سیستم‌های فاقد کارت گرافیک اختصاصی با مدل‌های سبک[cite: 3].

## 🇬🇧 English Version

A lightweight, modern, and minimalist desktop application designed to run Large Language Models (LLMs) **completely offline** using **Ollama**[cite: 3]. Built with a multi-agent pipeline architecture, it provides robust AI-assisted coding with full Persian language support[cite: 3].

### ✨ Key Features
* **Multi-Agent Pipeline:** Chain multiple models in a collaborative workflow (Persian Translator ➔ Logic Analyst ➔ Code Specialist ➔ Reverse Translator)[cite: 3].
* **Two-Way Smart Translator:** Translates Persian prompts into technical English and converts code explanations back into natural Persian[cite: 3].
* **Dual Execution Modes:** Seamlessly switch between "Single Mode" and "Multi-Agent Mode"[cite: 3].
* **Modern RTL UI & Dark Theme:** Built-in Right-to-Left support for Persian typography with a clean developer-friendly interface[cite: 3].
* **Local Chat History:** Automatically saves conversation logs locally (`ai_history.json`) without draining system RAM[cite: 3].
* **Advanced Controls:** Includes a live timer, progress loader, instant Stop button, and one-click clipboard copy[cite: 3].
* **Optimized for Low-End PCs:** Runs smoothly on CPU-only machines by leveraging lightweight, high-performance models[cite: 3].
