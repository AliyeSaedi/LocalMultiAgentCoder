# LocalMultiAgentCoder
مجموعه ابزاری پیشرفته و سبک برای برنامه‌نویسی آفلاین با هوش مصنوعی که امکان اجرای مدل‌های زبانی بزرگ را به صورت کاملاً محلی و از طریق موتور اولاما فراهم می‌کند. این نرم‌افزار با بهره‌گیری از یک معماری چندعاملی و پشتیبانی کامل از زبان فارسی، فرآیند توسعه نرم‌افزار را تسهیل کرده و شامل قابلیت‌هایی نظیر ترجمه دوطرفه، مدیریت هوشمند تاریخچه گفتگوها، حالت‌های اجرای تکی و زنجیره‌ای، و رابط کاربری مدرن تیره است که به طور ویژه برای سیستم‌های دارای سخت‌افزار معمولی و بدون کارت گرافیک اختصاصی بهینه‌سازی شده است.
